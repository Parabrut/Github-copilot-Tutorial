# GitHub Copilot Tutorial

This project is a simple front-end website built as a small business landing page. It is designed to show how a basic HTML and CSS project can become a real, usable webpage.

## Project Overview

The project currently includes:

- [index.html](index.html) — the main landing page
- [styles.css](styles.css) — styling for the page
- [login.html](login.html) — a basic login example
- [form.html](form.html) — a basic contact form example

## Purpose

This project is meant for learning how to:

- build simple web pages with HTML
- style pages with CSS
- structure a landing page for a real business idea
- deploy a static website on GitHub

## Run Locally

You can open the files directly in a browser, or run a local server:

1. Open the project folder in a terminal.
2. Run:

   python -m http.server 8000

3. Open this in your browser:

   http://localhost:8000

## Deploy on GitHub

The easiest way to deploy this project is with GitHub Pages.

### Steps

1. Create a new repository on GitHub.
2. Push your files to the repository.
3. In GitHub, open the repository.
4. Go to Settings > Pages.
5. Under Source, choose Branch.
6. Select main and the folder /root.
7. Click Save.
8. GitHub will give you a live URL like:

   https://yourusername.github.io/your-repository-name/

### Important

Your page must include an index.html file at the root of the repository for GitHub Pages to serve it as the homepage.
